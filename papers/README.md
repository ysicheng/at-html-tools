# Paper downloads

This folder holds public, downloadable PDF editions of papers listed on `writing.html`.

## Add a future paper

1. Add the accessible web edition as a standalone `.html` page in the repository root.
2. Place its public PDF in this folder using a short, stable filename such as `paper-title-web-edition.pdf`.
3. Add both **Read online** and **Download PDF** links to the paper card on `writing.html`.
4. Add a **Download PDF** action near the title of the paper's web page.
5. Add the web page—not the PDF—to `sitemap.xml`, then validate local links before opening a preview PR.

The web page is the reference version: it is searchable, linkable and more accessible. The PDF is the portable offline copy.
